# Security & Ethical Use Policy

## Authorized Use Only

`Invoke-NetStress` is engineered strictly for authorized network capacity testing, QoS/SQM validation, and bufferbloat benchmarking on networks and links that you personally own or have received formal, explicit authorization to assess.

### Prohibited Activities:
- Using this tool against unauthorized IP addresses, endpoints, or infrastructure.
- Generating Denial of Service (DoS/DDoS) conditions against third parties.
- Violating Internet Service Provider (ISP) Acceptable Use Policies (AUP).

The software includes built-in compliance checks requiring confirmation (`-AcknowledgeAuthorization` or `-AcceptTerms`) to verify operator authorization before execution.

## Reporting a Vulnerability

If you discover a security vulnerability or flaw in this tool:
1. Please do not open public issues disclosing the vulnerability.
2. Send a report to the repository maintainers with a detailed description and steps to reproduce.
3. We will acknowledge receipt within 48 hours and work on a prompt remediation.
